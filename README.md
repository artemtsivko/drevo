# 🌳 Рід — спільний родовід

Веб-додаток для ведення родоводу з автоматичним пошуком спільних родичів між користувачами.

## Можливості
- Вхід через Google
- Додавання родичів: ім'я, прізвище, дівоче прізвище, стать, дата/рік народження, місце народження, дата/місце смерті, нотатки
- До 2 батьків і до 20 дітей на людину, зв'язки подружжя
- 4 режими перегляду: **Дерево**, **Граф**, **Список**, **Провідник** (як папки)
- Пошук спільних родичів у публічних родоводах за іменем + роком народження + зв'язками
- Пропозиції об'єднання з підтвердженням/відхиленням
- Приватний або публічний родовід
- Запити доступу до повного родоводу і керування дозволами

## Запуск локально
```bash
npm install
cp .env.example .env   # заповніть значеннями з Firebase
npm run dev
```

## Стек
React + Vite · Firebase (Firestore + Auth) · Netlify

Повна покрокова інструкція з налаштування — у чаті / файлі `SETUP.md`.
